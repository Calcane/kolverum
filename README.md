# KOLVERUM

Official website source for **KOLVERUM**.

## Structure

- `index.html` — landing page and content
- `styles.css` — visual system and responsive layout
- `script.js` — minimal front-end interactions
- `robots.txt` — crawler directives
- `sitemap.xml` — initial sitemap

## Deployment

The site is designed as a static GitHub Pages website for `https://kolverum.com/`.

The custom domain and social/release links should be connected only when the corresponding destinations are live and verified.
